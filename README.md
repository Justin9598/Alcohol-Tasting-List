# Alcohol Tasting List

A personal record of bottles drunk and bought: what it was, where it came from and what
it cost. Sake led, but it covers eleven categories now.

The site is one self-contained page. Open `index.html`, or visit the published link.

Nothing here is hand written. The page is generated from a workbook kept outside this
repository, so **do not edit `index.html` directly**: the next build overwrites it.
